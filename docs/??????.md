# secure-artifacts 提交审核清单

本项目按“软件”审核类型准备，可通过 GitHub Actions 构建用户版 ZIP、生成 Artifact Attestation，并由 `github-actions[bot]` 创建 GitHub Release。

如果只希望进行静态源码扫描，也可以选择“源码审核”；该类型不要求 CI、Release 或 Attestation，但结果不会进入公开的软件列表。

## 1. 公开前安全自查

审核仓库必须公开。上传前逐项确认：

- [ ] 源码不含内部业务逻辑、内部 API 地址或内部数据结构。
- [ ] 源码不含账号、密码、令牌、证书、数据库连接串或其他密钥。
- [ ] README、注释和提交历史不含客户名称、内部人员或项目代号。
- [ ] 测试和示例不含真实业务数据。
- [ ] 项目离开内部网络后仍可独立运行。
- [ ] 已决定是否添加开源许可证。

只要任一项不确定，就不要把仓库公开或提交审核。

## 2. 建议的 GitHub 仓库信息

- 仓库名：`filename-suffix-cleaner`
- 显示名称：`Filename Suffix Cleaner`
- Description：`A safe Windows tool for removing _行xx_subtitled filename suffixes with collision protection and undo support.`
- 可见性：`Public`
- 默认分支：`main`

平台会自动读取 GitHub 仓库的 Description，因此请在提交前设置。

## 3. 加入组织并放置仓库

- [ ] 在安全管理平台选择“申请加入组织”。
- [ ] 填写 GitHub 用户名或主页链接及开发者名称。
- [ ] 接受 `secure-artifacts` GitHub 组织邀请。
- [ ] 推荐把个人仓库 Fork 到 `secure-artifacts`；也可以直接转移仓库。
- [ ] 最终仓库 URL 形如：

```text
https://github.com/secure-artifacts/filename-suffix-cleaner
```

## 4. 本地提交前验证

运行自动化测试：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-FilenameSuffixCleaner.ps1
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tests\Test-ReleaseWorkflow.ps1
```

重新构建发布包：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\tools\Build-Release.ps1
```

确保 `dist` 下生成：

```text
Filename-Suffix-Cleaner-v1.0.0.zip
```

## 5. 创建正式 Release

不要在 GitHub 页面手工上传 Release 文件，也不要使用个人 PAT。正式发布必须由 tag push 触发，并由项目自带的 `.github/workflows/release.yml` 使用默认 `GITHUB_TOKEN` 完成。

确认 `VERSION` 内容后执行：

```bash
git tag v1.0.0
git push origin v1.0.0
```

Workflow 会依次：

1. 校验 tag 与 `VERSION` 一致；
2. 运行自动化测试；
3. 构建最终用户 ZIP；
4. 生成 SHA256 校验文件；
5. 为 `dist/*` 生成 Artifact Attestation；
6. 由 `github-actions[bot]` 创建 Release 并上传全部产物。

## 6. Release 验证

- [ ] GitHub Actions workflow 成功完成。
- [ ] Release tag 与推送 tag 相同。
- [ ] 所有 Release assets 的上传者均为 `github-actions[bot]`。
- [ ] Release 中包含用户版 ZIP 和 `SHA256SUMS.txt`。
- [ ] GitHub Release 页面显示构建来源证明。
- [ ] 可选：使用 GitHub CLI 验证：

```bash
gh attestation verify Filename-Suffix-Cleaner-v1.0.0.zip --repo secure-artifacts/filename-suffix-cleaner
```

## 7. 提交项目审核

在安全管理平台选择“提交项目审核”，填写：

- 审核类型：`软件`
- GitHub 项目 URL：`https://github.com/secure-artifacts/filename-suffix-cleaner`
- 项目名称：`Filename Suffix Cleaner`（可选）
- 开发者名称：填写实际姓名

项目描述由平台从 GitHub Description 自动同步，无需在表单中另填。

Code Scanning、Secret Scanning 和 Push Protection 按平台文档由管理员在审核阶段统一配置，本项目不额外提交这些设置。
