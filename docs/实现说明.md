# 实现说明

## 1. 总体设计

项目由四个 PowerShell 脚本组成：

| 文件 | 职责 |
|---|---|
| `Remove-XxSubtitled.ps1` | 扫描目标文件夹、匹配文件名、执行安全改名并写入日志 |
| `Undo-XxSubtitled.ps1` | 查找目标文件夹最近一次未撤销日志并恢复原文件名 |
| `Install.ps1` | 把运行脚本复制到当前用户本地目录并注册文件夹右键菜单 |
| `Uninstall.ps1` | 删除右键菜单注册项和已安装脚本，保留恢复日志 |

CMD 文件只是方便普通用户双击或拖放的启动入口，核心逻辑均在 PowerShell 源码中。

## 2. 改名流程

1. 使用 `Resolve-Path` 解析目标文件夹。
2. 使用 `Get-ChildItem -File` 枚举当前层级文件。
3. 对 `BaseName` 应用后缀正则匹配。
4. 拼回原扩展名得到目标文件名。
5. 若目标路径已存在，则跳过，不覆盖任何文件。
6. 使用 `Rename-Item -LiteralPath` 执行改名。
7. 把成功记录写入 JSON 日志。
8. 显示成功数和跳过数。

脚本中以 `[char]0x884C` 构造“行”字，避免旧版 Windows PowerShell 对无 BOM UTF-8 脚本的编码兼容问题。

## 3. 日志格式

日志目录：

```text
%LOCALAPPDATA%\FilenameSuffixCleaner\logs
```

示例结构：

```json
{
  "Version": 1,
  "TargetPath": "D:\\Videos",
  "CreatedAt": "2026-08-09T12:00:00.0000000-07:00",
  "Records": [
    {
      "OldName": "demo_行1_subtitled.mp4",
      "NewName": "demo.mp4"
    }
  ]
}
```

成功撤销后，日志会增加 `UndoCompletedAt` 字段。撤销脚本会忽略已完成撤销的记录。

## 4. 撤销策略

撤销时逐条检查：

- 新文件存在且旧文件不存在：恢复原名。
- 旧文件存在且新文件不存在：视为已经恢复。
- 两者同时存在或同时不存在：视为冲突并跳过。

只有所有记录均恢复或已处于恢复状态，日志才会被标记为撤销完成，因此临时冲突处理后可以再次执行撤销。

## 5. 注册表项

安装脚本分别注册文件夹本身和文件夹空白处的右键菜单：

```text
HKCU\Software\Classes\Directory\shell
HKCU\Software\Classes\Directory\Background\shell
```

每处包含两个菜单项：

- `RemoveXxSubtitled`
- `UndoXxSubtitled`

安装范围为 `HKCU`，因此不要求管理员权限，也不会影响其他 Windows 用户。

## 6. 安装目录

运行脚本安装到：

```text
%LOCALAPPDATA%\FilenameSuffixCleaner
```

卸载会删除这里的两个运行脚本，但刻意保留 `logs` 文件夹。

## 7. 已知边界

- 默认只处理当前文件夹，不递归子文件夹。
- 只处理文件，不处理文件夹名称。
- 撤销依据日志中的文件名；若文件在操作后被移动或再次手工改名，则相应记录可能无法恢复。
- Windows 11 默认把传统注册表右键项放在“显示更多选项”中。
